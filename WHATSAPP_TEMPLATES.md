# WhatsApp templates for group scheduling

Replace `{LINK}`, `{TITLE}`, `{TIME}`, and `{MEET}` before sending.

One **unique link per call** — never reuse a link across different groups.

---

## 1. New group link (post when scheduling starts)

**English**
```
Hi everyone 👋

Please share when you're available for our call with Jens.

👉 Pick 3–5 times that work for you (Lisbon time):
{LINK}

• Use the same email if you need to change your times later
• Green slots = times someone else already picked — overlapping helps us schedule faster

Jens will confirm the final time here once everyone has responded.
```

**Nederlands**
```
Hoi allemaal 👋

Deel wanneer jullie beschikbaar zijn voor ons gesprek met Jens.

👉 Kies 3–5 momenten die voor jou passen (Lisbon-tijd):
{LINK}

• Gebruik hetzelfde e-mailadres als je je tijden later wilt aanpassen
• Groene slots = iemand anders koos die tijd al — overlap maakt plannen makkelijker

Jens bevestigt de definitieve tijd hier zodra iedereen heeft ingevuld.
```

## 5. You’re scheduling several separate calls

Use this note for yourself / your agent — **not** for the group:

```
This week: 5 separate 3-way calls = 5 different links in admin.
Do not paste the same link in multiple WhatsApp groups.
```

---

## Where to get the link

1. Open https://book-a-call.jensvandenbroeke.com/admin  
2. **Group scheduling** → **New group link**  
3. Choose guest count (2 guests = 3-way with you)  
4. **Copy WhatsApp link** → paste into the group
